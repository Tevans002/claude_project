Gale-Shapley(preference lists for n hospitals and n students)
    Let M be an empty matching
    While some hospital h is unmatched and hasn’t proposed to every student:
        Let s be the first student on h’s list to whom h has not yet proposed
        If s is unmatched:
            Add (h, s) to M
        Else s is matched to h′:
            If s prefers h to h′:
                Remove (h′, s) from M
                Add (h, s) to M
            Else s prefers h′ to h:
                Do nothing
    Return M

## Tool 3 (NEXT): P / NP / NP-Complete / NP-hard
Folder: project/complexity/ (complexity.html, data.js, ui.js, game.js).
When it's done, update index.html card 3 to link to it.

Exam question: "True or False. Assume P ≠ NP."
(a) Every problem in NP is also in P.                                  F
(b) Every problem in P is also in NP.                                  T
(c) NP is the set of problems that cannot be solved in poly time.      F
(d) If A is NP-Complete, then A is in NP.                              T
(e) If A is NP-Complete, then A is in P.                               F
(f) If A is in NP, there is a poly-time verifier for yes instances.    T
(g) Poly reduction from A to NP-hard B => A is NP-hard.                F
(h) Poly reduction from NP-hard A to B => B is NP-hard.                T

Agreed design (two ideas only):
1. Animated Euler diagram: P inside NP; NP-hard overlaps NP's edge; NP-Complete is the
   overlap. Problems appear as dots. For each statement the user picks T/F, then
   "proves" it: for False, click a counterexample dot; for True, the deciding region
   highlights. A wrong answer red-boxes the deciding phrase in the statement
   (e.g. "cannot be solved", "from A to B").
2. Reduction arrow animation (for g/h-style statements): two problem cards with arrow
   A → B. A "hardness" pulse travels from the hard problem along the arrow to B.
   Counterexample for (g): Sorting → SAT is a valid reduction, but Sorting is easy.
Goal: reinforce HOW to answer each exam statement, not just memorize T/F.

Course example problems: Clique, Vertex Cover, Independent Set, SAT (all NP-Complete).
Reductions to show: Clique ≤ Independent Set, Independent Set ≤ Vertex Cover,
SAT/3-SAT ≤ Independent Set.

Variants for "New problem": reworded versions of the same 8 traps (e.g. "from B to A",
"NP-hard problems are in NP"), including some that assume P = NP. Under P = NP the
diagram collapses (P = NP = NP-Complete region inside NP-hard). Answers change:
(a) T, (e) T, and (b) (c) (d) (f) (h) are unchanged. (g) stays F but is subtle
(trivial problems are never NP-hard), so be careful or skip it.
